Aura KittyTech: Prototipo de captura volumétrica y renderizado 3D en tiempo real para estilismo mediante escaneo infrarrojo

El proyecto consiste en el desarrollo de un pipeline gráfico y de captura diseñado para revolucionar la experiencia de consultoría estética. Se captura la topología craneal y facial del cliente mediante un ensamble de sensores infrarrojos (IR). Esta información volumétrica es procesada mediante algoritmos de automatización en herramientas de escaneo para generar una malla 3D base. Posteriormente, a través de un motor de renderizado en tiempo real desarrollado para PC y tabletas utilizando Unity y herramientas de modelado como Blender, el motor permite superponer, ajustar y previsualizar diferentes cortes de cabello, colores y estilos con físicas en tiempo real. Esto permite al usuario interactuar con su "gemelo digital" antes de que el estilista realice cualquier intervención física.

Objetivo General:
Desarrollar un prototipo funcional de previsualización estética en 3D, integrando captura volummetrica por sensores infrarrojos y renderizado en tiempo real, para optimizar la consulta y elección de estilos en centros de belleza.
